# Инструкция для новичка

## Макет под печать в Figma за 10 минут

Эта инструкция — для случая, когда вы никогда не ставили плагины и не готовили
файлы для типографии. Ниже — по шагам, без сложных слов. Термины объясняются
в конце, в «Словарике».

Плагин работает в **Figma 2026** (и в более старых версиях тоже). Ему не нужен
интернет и не нужны другие программы.

---

## Что понадобится

1. Компьютер с Windows или macOS.
2. **Figma для компьютера** (десктопное приложение), а не Figma в браузере.
   Скачать: `https://www.figma.com/downloads/` → Download for Windows / macOS.
3. Папка с плагином. Она уже есть:

   ```
   C:\Users\user\Documents\Проект по умолчанию\figma-print
   ```

   Внутри должны лежать три файла: `manifest.json`, `code.js`, `ui.html`.
   Именно эти три файла — сам плагин. Больше ничего не нужно.

---

## Часть 1. Установка плагина

Это делается **один раз**. Потом плагин всегда будет в меню Figma.

### Шаг 1. Откройте Figma

Запустите приложение Figma, войдите в свой аккаунт (или зарегистрируйтесь —
это бесплатно) и откройте любой файл. Можно создать новый: **New design file**.

### Шаг 2. Найдите меню плагинов

В Figma 2026 меню находится в **левом верхнем углу** — нажмите на логотип
Figma (или значок `≡`).

Дальше:

**Plugins → Development → Import plugin from manifest…**

Если такого пути не видите, есть два запасных варианта — они работают
в любой версии Figma:

- **Правый клик** по пустому месту на холсте → **Plugins → Development →
  Import plugin from manifest…**
- Нажмите **Ctrl + /** (на Mac — **Cmd + /**), начните печатать
  `Import plugin` и выберите появившийся пункт.

> Если пункта **Development** нигде нет — вы открыли Figma в браузере.
> Нужно именно приложение. Либо у вас очень старая версия — обновите её.

### Шаг 3. Выберите файл

Откроется окно выбора файла. Нужно выбрать:

```
figma-print\manifest.json
```

Как быстро попасть в нужную папку: в окне выбора файла нажмите
**Ctrl + L** (на Mac — **Cmd + Shift + G**), вставьте путь
`C:\Users\user\Documents\Проект по умолчанию\figma-print` и нажмите Enter.

Выберите `manifest.json` → **Открыть**.

### Шаг 4. Проверьте

Плагин появился в меню **Plugins → Development** под названием
**«Whoosh — Off to Print!»**.

Всё, установка закончена. Закрывать Figma не нужно.

---

## Часть 2. Создаём макет

1. Откройте плагин: **Plugins → Development → Whoosh — Off to Print!**
   (или правый клик по холсту → Plugins → Development → …).
2. Откроется небольшое окно. Вы уже на вкладке **«Макет»**.
3. Нажмите квадратик с нужным форматом: **A4**, **A3**, **A2**, **A1**, **A0**,
   **A5**, **A6**, **B1**, **B2**, **Letter** — или «Свой размер» и впишите
   ширину и высоту в миллиметрах.
4. **Ориентация** — «Книжная» (вертикально) или «Альбомная» (горизонтально).
5. **Вылеты (bleed)** — оставьте **3 мм**. Это стандарт почти всех типографий.
6. **Поля безопасности** — оставьте **5 мм**.
7. **DPI для растра** — оставьте **300 dpi**.
8. **Фон (бумага)** — белый.
9. Нажмите большую кнопку **«Создать макет»**.

На холсте появится большой кадр с названием вроде
`[PRINT] A4 210×297мм + 3мм вылет`.

### Что означают цветные рамки

- **Красная пунктирная рамка** — линия реза. По ней типография разрежет лист.
  Всё, что должно быть на готовом изделии, — внутри неё.
- **Синяя рамка** — безопасная зона. Здесь держим текст, логотипы и всё важное,
  чтобы это не отрезали.
- **Оранжевая рамка** — край кадра, граница вылетов.
- Если рамки мешают, уберите галочку **«Показывать направляющие»**
  на вкладке «Экспорт». На экспорт они не влияют.

---

## Часть 3. Рисуем макет

Главное правило: **всё рисуем внутри кадра**, а не рядом на сером холсте.
Если нарисовать рядом, в файл это не попадёт.

1. Выберите инструмент (Rectangle, Text и т. д.) и рисуйте **внутри кадра**.
   Новые объекты автоматически становятся частью кадра.
2. **Фон, фотографии и цветные плашки**, которые должны доходить до края,
   растягивайте **за красную линию** — до самого края кадра. Это и есть вылеты:
   после резки не будет белой полоски.
3. **Текст и логотипы** держите **внутри синей рамки**.
4. Служебные слои, которые не должны попасть в файл, называйте с подчёркиванием
   в начале: `_заметки`, `_черновик`. Плагин их скроет при экспорте.
5. Слои `_TRIM`, `_SAFE`, `_BLEED` не трогайте и не переименовывайте — это
   направляющие. Они заперты и в экспорт не попадают.

Проверка: в панели слоёв слева ваши объекты должны быть **внутри** кадра
`[PRINT] …`, а не над ним и не рядом.

---

## Часть 4. Экспорт

1. Откройте вкладку **«Экспорт»** в окне плагина.
2. Сверху выберите ваш макет. Если он выделен на холсте, он уже выбран.
3. Проверьте галочки — по умолчанию всё правильно:
   - **Текст в кривые** — включено (шрифты не понадобятся типографии);
   - **PDF в CMYK** — включено;
   - **Картинки в PDF тоже в CMYK** — включено;
   - **Обрезка макетов** — «Убирать (для Illustrator)».
4. Нажмите **«PDF для печати»**.
5. Браузер (внутри Figma) может спросить разрешение на скачивание —
   разрешите. Файл появится в папке **Загрузки / Downloads**.

Имя файла будет вроде `A4_210x297mm_bleed3.pdf`.

Если нужно несколько макетов в одном файле, поставьте галочку
**«Все макеты страницы — в один PDF»** и снова нажмите кнопку.

### Другие кнопки

- **SVG для Illustrator / CorelDRAW** — если будете дорабатывать макет
  в этих программах. Размеры уже в миллиметрах, лишних обрезок нет.
- **PNG с реальным DPI** — картинка для согласования. 300 dpi — настоящие 300 dpi.
- **JPG с реальным DPI** — то же самое, но легче по весу.

## Часть 5. Что отправлять в типографию

Отправляйте **PDF для печати**. Этого достаточно.

Внутри PDF уже есть:

- размер страницы с вылетами (для A4 — 216×303 мм);
- обрезной формат 210×297 мм (типография «видит» его как TrimBox и режет по нему);
- текст в кривых;
- цвета в CMYK.

Напишите типографии примерно так:

> Здравствуйте! Макет A4, 210×297 мм, вылеты 3 мм, CMYK, текст в кривых.
> Файл PDF прилагаю.

Этих слов достаточно, чтобы вас поняли.

### Если хотите проверить файл сами

Откройте PDF в Adobe Illustrator или бесплатном Adobe Acrobat Reader:

- размер страницы должен быть **216×303 мм** (это A4 + вылеты);
- при открытии в Illustrator выберите **Crop to: TrimBox** — тогда покажется
  ровно **210×297 мм**;
- текст и фигуры должны выделяться как обычные объекты, а не как «картинка».

---

## Часть 6. Цвета CMYK (необязательно)

Figma умеет работать только в RGB — так устроена программа. Но для печати нужен
CMYK. Плагин переводит цвета сам, этого обычно достаточно.

Если типография дала вам точные CMYK-числа (например, «фирменный красный
0/100/100/0»), сделайте так:

1. Откройте вкладку **«CMYK»**.
2. Введите C, M, Y, K в процентах.
3. Нажмите **«Создать стиль в Figma»**.
4. Выделите объект → правая панель → **Fill** → выберите созданный стиль
   `CMYK 0/100/100/0`.

Тогда в PDF уйдут ровно эти числа.

## Если что-то не получается

| Что случилось | Что делать |
|---|---|
| В меню нет **Development** | Вы в браузере. Откройте Figma для компьютера |
| При импорте ошибка **Manifest error** | Выбран не тот файл. Нужен именно `manifest.json`, и рядом должны лежать `code.js` и `ui.html` |
| Плагин открылся, но список макетов пуст | Создайте макет на вкладке «Макет» или выделите кадр на холсте |
| **Файл получился пустой** | Рисунок должен быть **внутри** кадра. Если макет создан старой версией плагина — закройте и снова откройте плагин, теперь рисунок экспортируется. Если не помогло — пришлите лог с вкладки «Экспорт» |
| Браузер не даёт скачать файл | Разрешите скачивание нескольких файлов для Figma |
| В PDF «не те» цвета | Примените стили с вкладки «CMYK» или проверьте, что не стоит прозрачность/эффекты |
| Текст в PDF изменился | Включите «Текст в кривые» и экспортируйте заново |
| В Illustrator вектор обрезан | Экспортируйте с обрезкой «Убирать (для Illustrator)» |

Лог работы — внизу вкладки «Экспорт». Если что-то пошло не так, там обычно
написано, что именно.

## Словарик

- **Вылеты (bleed)** — запас по краям макета, который потом отрезается.
  Нужен, чтобы после резки не осталось белой полоски.
- **Линия реза** — где типография разрежет лист. В плагине это красная рамка.
- **TrimBox** — обрезной формат, «чистый» размер изделия (например, A4).
- **Безопасная зона** — место, где текст не отрежут. Синяя рамка.
- **DPI** — разрешение картинки. Для печати — 300 dpi.
- **CMYK** — четыре краски печати: голубая, пурпурная, жёлтая, чёрная.
- **Кривые** — текст, превращённый в контуры. Тогда ему не нужен шрифт.
- **Вектор** — рисунок из линий и фигур, а не из пикселей. Не «мылится»
  при увеличении.

## Мини-чеклист перед отправкой

- [ ] Формат и ориентация правильные.
- [ ] Вылеты 3 мм (или те, что просила типография).
- [ ] Фон и картинки доходят до края кадра.
- [ ] Текст и логотипы внутри синей рамки.
- [ ] Экспортирован **PDF для печати**.
- [ ] При открытии PDF размер 210×297 мм (для A4) по TrimBox.
- [ ] Текст в PDF — кривые, цвета CMYK.

Всё. Можно отправлять.
