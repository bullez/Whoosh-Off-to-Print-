Whoosh — Off to Print! макеты под печать: формат, DPI, вылеты, CMYK

Кадр получится размером «обрез + вылеты». Красная рамка — линия реза, синяя — безопасная зона. Служебные слои _TRIM, _SAFE, _BLEED заперты и в экспорт не попадают. Рисуйте поверх них.

Готово к работе.

Figma работает только в RGB. Соберите цвет из CMYK-чисел — плагин создаст стиль с точным пересчётом, и в PDF этот цвет уйдёт ровно теми же CMYK-числами.

Подробная инструкция
Пошаговое руководство для новичка лежит рядом с плагином — файл ИНСТРУКЦИЯ.md в папке figma-print.
Как получить макет под типографию
1. Вкладка «Макет» → формат, вылеты 3 мм, DPI 300 → «Создать макет».
2. Рисуйте внутри кадра, фон и картинки заводите за красную линию (в вылеты).
3. Важное держите внутри синей рамки (безопасная зона).
4. Вкладка «Экспорт» → «PDF для печати».
5. Файл откройте в Illustrator: это обычные редактируемые контуры, без групп-обрезок.
Размеры, которые вы получите
A4 без вылетов → страница 210×297 мм.
A4 с вылетом 3 мм → страница 216×303 мм, а обрезной формат (TrimBox) = 210×297 мм. Типография режет по TrimBox, поэтому формат остаётся A4.
Почему CMYK — это приблизительно
Экран показывает sRGB, у печати гамма уже. Плагин переводит цвета по стандартной формуле (без ICC-профиля типографии). Чёрный текст становится чистым K, а не «составным». Если нужна цветопроба по профилю — откройте PDF в Illustrator и примените профиль типографии.
Если что-то не попало в файл
Эффекты (тени, размытие) и градиенты с прозрачностью в PDF упрощаются. Слои, имя которых начинается с _, не экспортируются вообще — так служебные направляющие не мешают.
