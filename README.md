# Whoosh — Off to Print! — плагин Figma для макетов под печать

Готовый бесплатный плагин: делает кадры типографских форматов (A6…A0, B1, B2, Letter),
считает вылеты и безопасную зону, а на выходе отдаёт **PDF в CMYK** с правильными
TrimBox/BleedBox, **чистый SVG** для Illustrator/CorelDRAW, а также PNG/JPG
с настоящим DPI (300 dpi — это правда 300 dpi, а не «примерно»).

Ничего собирать и устанавливать не нужно: плагин уже готов, лежит в этой папке.
Интернет ему не требуется, работает офлайн.

> **Совсем новичкам:** есть отдельная пошаговая инструкция простым языком —
> [`ИНСТРУКЦИЯ.md`](ИНСТРУКЦИЯ.md). В ней расписано, куда нажимать в Figma 2026,
> как рисовать и что отправлять в типографию. Ниже — более подробная
> техническая документация.

---

## 1. Что где лежит

Папка плагина: `figma-print` (та, в которой вы сейчас читаете этот файл).

| Файл | Что это | Трогать? |
|---|---|---|
| `manifest.json` | «Паспорт» плагина — его выбирает Figma при установке | нет |
| `code.js` | Основной код плагина (создание макетов, экспорт) | нет |
| `ui.html` | Окно плагина — уже собранное, со всем кодом внутри | нет |
| `README.md` | Эта инструкция | — |
| `src/` | Исходники окна и движков SVG/PDF | только для правок |
| `build.mjs` | Сборка `src/*` → `ui.html` | только для правок |
| `tests/` | Тесты для разработки | можно удалить |

Для работы плагина нужны **только первые три файла**. Их можно скопировать
в любую папку, например `C:\FigmaPlugins\vylet-i-slezy\` — главное, чтобы
`manifest.json`, `code.js` и `ui.html` лежали рядом.

## 2. Установка в Figma (5 минут)

1. Скачайте и запустите **Figma для Windows** (десктопное приложение).
   Важно: установка плагина из файла работает только в приложении, не в браузере.
2. Войдите в свой аккаунт и откройте любой файл.
3. В левом верхнем углу нажмите **меню Figma** (иконка `≡` / логотип) →
   **Plugins** → **Development** → **Import plugin from manifest…**
4. В открывшемся окне выберите файл
   `figma-print\manifest.json` и нажмите «Открыть».
5. Готово: плагин появился в меню **Plugins → Development** под именем
   «Whoosh — Off to Print!».

> Если пункта **Development** нет — вы в браузере или у вас старая версия Figma.
> Обновите десктопное приложение.

Запуск в дальнейшем: **Plugins → Development → Whoosh — Off to Print!**
(или правый клик по холсту → Plugins → Development → …).

## 3. Как сделать макет

Откройте плагин. Первая вкладка — **«Макет»**.

1. **Формат** — нажмите чип `A4`, `A3`, `A2`, `A1`, `A0`, `A5`, `A6`, `B1`, `B2`,
   `Letter` или «Свой размер» и впишите ширину/высоту в мм вручную.
2. **Ориентация** — книжная или альбомная.
3. **Вылеты (bleed)** — оставьте `3 мм` (стандарт типографий). Если типография
   просит другое, выберите 2/5/10 мм или `0`.
4. **Поля безопасности** — `5 мм` по умолчанию. Это зона, ближе к краю которой
   нельзя ставить текст и важные элементы.
5. **DPI для растра** — `300` для печати (150 — для черновика, 600 — для мелкой
   полиграфии/картинок с мелким растром).
6. **Фон (бумага)** — цвет подложки кадра, обычно белый.
7. Имя макета — необязательно, попадёт в имя файла при экспорте.
8. Нажмите **«Создать макет»**.

Появится кадр с именем `[PRINT] A4 210×297мм + 3мм вылет` и тремя запертыми
служебными слоями `_TRIM`, `_SAFE`, `_BLEED` (они лежат под рисунком):

- **красная пунктирная рамка** — линия реза (обрезной формат);
- **синяя рамка** — безопасная зона;
- **оранжевая рамка** — граница вылетов (= край кадра).

Как рисовать:

- Всё рисуйте **внутри кадра**, а не рядом на холсте.
- Фон, фотографии, плашки, которые должны доходить до края, заводите
  **за красную линию**, до самого края кадра (в вылеты).
- Текст и логотипы держите **внутри синей рамки**.
- Служебные слои, которые не должны попасть в файл, называйте с подчёркиванием
  в начале: `_notes`, `_черновик`. Плагин их скрывает при экспорте.
- Направляющие (`_TRIM`, `_SAFE`, `_BLEED`) можно спрятать/показать галочкой
  «Показывать направляющие» на вкладке «Экспорт».

Макетов на странице может быть сколько угодно — они запоминаются в файле
(данные хранятся в самом кадре), список появится на вкладке «Экспорт».

## 4. Экспорт

Вкладка **«Экспорт»**. Сверху выберите, что экспортируем:

- **выделенный кадр** (если что-то выделено на холсте — оно и берётся), или
- любой ранее созданный печатный макет из списка.

Галочка **«Все макеты страницы — в один PDF»** соберёт многополосный PDF.

Настройки:

- **DPI растра** — 150/300/600, влияет на PNG/JPG и на растровые картинки
  внутри PDF.
- **Обрезка макетов** — `Убирать (для Illustrator)` — рекомендуемый режим.
  Он выкидывает из файла Figma-шные группы-маски, из-за которых в Illustrator
  вектор выглядит «спрятанным» или обрезанным. `Сохранять` — если маска
  действительно нужна (например, фото в круге).
- **Текст в кривые** — держите включённым: шрифты не придётся отдавать
  в типографию, и ничего не «поедет».
- **PDF в CMYK (DeviceCMYK)** — переводит цвета в CMYK.
- **Картинки в PDF тоже в CMYK** — растровые изображения пересчитываются
  в CMYK (без ICC-профиля, см. ограничения).

Кнопки:

### PDF для печати
Главный формат для типографии. Внутри:

- векторные контуры, текст в кривых;
- страница = обрезной формат + вылеты с двух сторон;
- **TrimBox** = чистый формат (например A4 = 210×297 мм),
  **BleedBox** = с вылетами (216×303 мм);
- цвета в DeviceCMYK;
- никаких clip-групп и «мусорных» обрезок.

Имя файла: `A4_210x297mm_bleed3.pdf`, а если вы задали своё имя —
`Poster_A2_final_420x594mm_bleed3.pdf`.

### SVG для Illustrator / CorelDRAW
Чистый вектор: размеры прописаны в миллиметрах (`width="216mm"`), координаты
в пунктах, `clipPath` удалены, градиенты перенесены в `defs` с новыми id.
Удобно, когда нужно быстро доработать макет в Illustrator.

### PNG / JPG с реальным DPI
Растр в выбранном разрешении, причём в файл записан настоящий DPI
(PNG-чанк `pHYs`, JPEG-плотность JFIF). Illustrator, Photoshop и CorelDRAW
покажут физический размер в мм, а не «пиксели».

Лог внизу окна показывает, что происходит и что не удалось перенести.

## 5. Вкладка «CMYK»

Figma умеет только RGB, поэтому «сделать CMYK» внутри Figma нельзя в принципе.
Плагин решает это так: вы задаёте CMYK-числа, он создаёт **стиль заливки**
с таким RGB, который при экспорте в PDF вернётся ровно в те же CMYK-числа.

1. Введите C/M/Y/K в процентах (или нажмите быстрый цвет: чёрный текст,
   богатый чёрный, красный, синий и т. д.).
2. Посмотрите на образец — так цвет будет выглядеть на экране (приблизительно).
3. **«Создать стиль в Figma»** — появится стиль с именем `CMYK 0/100/100/0`.
4. Примените этот стиль к объектам: выделить объект → правая панель →
   Fill → выбрать стиль из библиотеки.

Такой цвет уйдёт в PDF точными CMYK-числами, без «двойного пересчёта».

## 6. Как открыть результат в Illustrator / CorelDRAW

**Illustrator:** `File → Open` → выберите PDF. В диалоге Import PDF выбрать
`Crop to: TrimBox` — Illustrator покажет ровно обрезной формат.
Проверить: `Window → Attributes` / `Document Setup` — размер должен быть
210×297 мм (для A4). Контуры редактируются как обычные paths.

**CorelDRAW:** `File → Import` (Ctrl+I) → выберите PDF, в настройках импорта
поставьте `Curve` / `Text: Curves`, единицы — миллиметры.

Что проверить перед отправкой в типографию:

- размер страницы (TrimBox) совпадает с заказанным;
- вылеты 3 мм есть со всех сторон;
- текст в кривых, шрифты не запрашиваются;
- чёрный текст — один K, а не составной;
- нет объектов за пределами вылетов.

## 7. Ограничения (честно)

- **CMYK считается по простой формуле, без ICC-профиля.** Для большинства
  макетов (плашки, текст, простые картинки) этого достаточно, но это не
  цветопроба. Если типография даёт свой профиль — откройте PDF в Illustrator
  и примените его там (`Edit → Assign Profile` / `Convert to Profile`).
- **Эффекты Figma** (тени, размытие, inner shadow) в PDF упрощаются или
  пропадают — плагин пишет об этом в лог. Такие места лучше растрировать
  или собрать вручную.
- **Прозрачность градиентов** (`stop-opacity`) при экспорте в PDF игнорируется;
  сама заливка градиентом переносится.
- **Живой текст** (если снять галочку «Текст в кривые») выводится стандартными
  PDF-шрифтами — внешний вид может отличаться. Для печати всегда оставляйте
  галочку включённой.
- **Режим «Сохранять обрезку»** переносит Figma-маски как есть: в Illustrator
  это снова будут группы с clipping path. Для типографии обычно нужен
  режим «Убирать».
- Плагин не делает спуски полос, метки реза, приводки и цветопробные шкалы —
  это делает типография или препресс-софт.

## 8. Если что-то не работает

| Проблема | Что делать |
|---|---|
| В меню нет пункта **Development** | Откройте Figma именно в десктопном приложении |
| «Manifest error» при импорте | Проверьте, что выбрали `manifest.json`, а рядом лежат `code.js` и `ui.html` |
| Плагин открылся, но список макетов пуст | Выделите кадр на холсте или создайте макет на вкладке «Макет» |
| Кнопка экспорта ничего не делает | Посмотрите лог внизу вкладки «Экспорт»; скорее всего, кадр удалён или выделен не кадр |
| Файл экспортировался, но он пустой | Рисунок должен лежать **внутри** печатного кадра. Если кадр создан старой версией плагина, объекты могли попасть в служебный слой `_GUIDES` — обновите файлы плагина, закройте и снова откройте его: теперь такой рисунок экспортируется, а направляющие скрываются по одной |
| Браузер блокирует скачивание | Разрешите скачивание нескольких файлов для Figma |
| В PDF «поехали» цвета | Убедитесь, что объекты залиты стилями с вкладки «CMYK», а не произвольными RGB-цветами |
| В Illustrator вектор выглядит обрезанным | Экспортируйте заново с режимом обрезки `Убирать (для Illustrator)` |
| Текст в PDF стал «квадратиками» | Включите «Текст в кривые» и экспортируйте снова |

## 9. Для разработчика (необязательно)

Плагин написан на чистом JS, без npm-зависимостей. Исходники окна — в `src/`:

- `src/core-svg.js` — разбор SVG от Figma, чистка clip-path, мм-единицы;
- `src/core-pdf.js` — свой генератор PDF (CMYK, градиенты, PNG/JPEG, TrimBox);
- `src/ui.html` + `src/ui.js` — интерфейс.

После правок в `src/` пересоберите `ui.html`:

```
cd figma-print
node build.mjs
```

(подойдёт любой Node.js 18+). В `ui.html` подставляются три блока:
`core-svg.js`, `core-pdf.js` и `ui.js`.

Тесты (нужен Node.js и, для проверки PDF, Python с `pypdf`/`PyMuPDF`):

```
node tests/run.mjs
```

Папку `tests/` можно спокойно удалить — на работу плагина она не влияет.

Лицензия: делайте что хотите, только не продавайте как свой плагин.
